# UNION catalog research data

Generated by `npm run crawl:union -- --category=pulls` from UNION's public English catalog. Lever handles use `--category=levers`.

The importer stores factual specifications and source/image URLs. It does not download or republish UNION photography, drawings, logos, or marketing copy. UNION retains all rights in its catalog content and assets. Confirm permission and the site's current terms before redistributing data or using assets in a public product.

Each record retains its canonical source URL and crawl timestamp. Dimensions and installation details are reference data, not verified fabrication instructions. Always confirm the current manufacturer documentation before production.

The crawler is resumable, limited to one request at a time, and defaults to a 1.2-second delay between requests. Use `--limit=1` for a single catalog page and `--delay=2000` for a slower crawl.
